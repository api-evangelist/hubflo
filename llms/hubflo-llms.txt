# Hubflo Documentation

> The Hubflo API allows you to write and read data from the Hubflo application. It conforms to [REST](https://en.wikipedia.org/wiki/REST). It has predictable resource-oriented URLS, accepts JSON request bodies, returns JSON and uses standard HTTP status codes and verbs.

The request carries an `X-Hubflo-Signature` header containing the hex-encoded HMAC-SHA256 of the raw request body, computed with the webhook's signing secret (returned as `secret` when the webhook is created). To verify a delivery, recompute the HMAC over the received body with your signing secret and compare it to the header value.  Each delivery's payload also includes a unique `webhook_delivery_id` (along with a `webhook_delivery_created_at` timestamp).
